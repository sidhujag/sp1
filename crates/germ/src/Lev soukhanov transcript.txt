Lev soukhanov: rough explanation is that we have this notion of ADP program

it is a collection of matrices M_0, ..., M_n

given witness w_0, ..., w_n you compute

det(\sum w_i M_i)

and if det=0 it means program accepted input, and det != 0 means it rejected input
yeah, this is just an arithmetic circuit

similar to r1cs
it is not booleanized

in original ADP it is

but for us it is arithmetic

this is like THE reason we are trillion times more efficient

so how it works is that each gate (which all have slightly more general form than r1cs, they look like ab=cd for some linear combinations a, b, c, d) corresponds to some term in all M_i-s

basically each M_i is secretly sum of many matrices, let's call M_i^j one this matrix. j corresponds to gate index

ok?
now, the main instrument is rank additivity

when you compute individual gate contribution CONTRIB^j = \sum w_i M_i^j then this CONTRIB^j has following property

1. when gate j holds, this matrix has rank 2 with overwhelming probability
2. when gate j is broken, this matrix has rank 4
public inputs, they are baked in circuit structure

so let me continue. this ADP is morally analogue of something like groth, WE is built from this
so anyway totally these matrices are 2m+1 x 2m+1

so if all gates hold, each contribute rank 2 and by rank (sub)additivity we get rank 2m

but if even one is broken, we get rank 2m+1 and det != 0
it is standalone construction

downside is it is not reduced to any standard assumption

but upside is that it is by far, orders of magnitude more efficient than pretty much everything
